# Từ điển thuật ngữ và bảng số liệu (tra nhanh)

## 1. Từ điển: nói gì thay cho thuật ngữ khó

| Thuật ngữ | Nghĩa đơn giản | Nên nói |
|---|---|---|
| Máy chủ (server) | Máy tính làm việc ở xa, xử lý yêu cầu của người dùng | "máy chủ trên đám mây" |
| Đám mây (cloud) | Thuê máy của công ty lớn thay vì tự mua | "chạy trên đám mây" |
| Cơ sở dữ liệu (database) | Cuốn sổ cái điện tử | "nơi lưu toàn bộ dữ liệu" |
| Bảng (table) | Một trang trong sổ cái (đoàn viên, hoạt động...) | "bảng dữ liệu" |
| Giao diện (UI/frontend) | Phần người dùng nhìn thấy và bấm | "giao diện" |
| Phía máy chủ (backend) | Phần xử lý bên trong | "phần xử lý" |
| API / Server Action | Cổng để giao diện gửi yêu cầu cho máy chủ | "yêu cầu gửi lên máy chủ" |
| Xác thực (authentication) | Chứng minh "bạn là ai" | "đăng nhập" |
| Phân quyền (authorization) | Quy định "bạn được làm gì" | "phân quyền" |
| Băm mật khẩu (hash) | Biến mật khẩu thành chuỗi không dịch ngược được | "không lưu mật khẩu thật" |
| Mã hóa HTTPS | Đóng kín dữ liệu khi đi trên mạng | "đường truyền được mã hóa" |
| Token | Vé có thời hạn chứng minh quyền | "mã có hạn" |
| JWT | Loại vé có chữ ký số | "mã có chữ ký, không làm giả được" |
| Giao dịch (transaction) | Làm trọn bộ hoặc không làm gì | "làm trọn bộ hoặc hủy hết" |
| PWA | Web cài được như ứng dụng | "ứng dụng cài từ trình duyệt" |
| Service Worker | Phần chạy nền giúp nhận thông báo | "thành phần nhận thông báo" |
| Web Push | Thông báo đẩy tới điện thoại | "thông báo trên màn hình khóa" |
| Passkey / WebAuthn | Đăng nhập bằng vân tay/khuôn mặt chuẩn quốc tế | "đăng nhập bằng vân tay" |
| Pooler | Bộ gom kết nối để nhiều người dùng cùng lúc | "bộ chia kết nối" |
| Cron | Việc tự chạy theo lịch | "tác vụ tự chạy hằng ngày" |
| Cache (lưu đệm) | Giữ sẵn kết quả để mở nhanh | "lưu sẵn để mở nhanh" |
| Skeleton | Khung xám hiện trong lúc tải | "khung chờ khi tải" |
| Audit log | Nhật ký ai làm gì | "nhật ký thao tác" |
| Nonce | Mã ngẫu nhiên đổi để vô hiệu mã cũ | "mã làm mới để mã cũ hết hiệu lực" |
| Seed | Nạp dữ liệu mẫu | "dữ liệu mẫu" |
| Deploy | Đưa hệ thống lên mạng | "triển khai" |
| Open source | Mã nguồn công khai | "mã nguồn mở" |

| Mã QR hết hạn sau | **90 giây** |

| Mật khẩu tạm | **10 ký tự** ngẫu nhiên, mật khẩu mới tối thiểu **8 ký tự** |

| Tạo Chi đoàn kèm danh sách | tối đa **100** đoàn viên mỗi lần |
| Ảnh | JPG/PNG/WebP, tối đa **5 MB** |
| Tệp đính kèm bài viết | PDF/Word/Excel/PowerPoint, tối đa **10 MB**, tối đa **10 tệp** |
| Thiết bị đăng nhập nhanh | tối đa **5** mỗi tài khoản |

| Dung lượng gói hiện tại | **500 MB**, đủ khoảng **7–8 năm** |
| Giữ thông báo | đã đọc **90 ngày**, chưa đọc **120 ngày** |
| Giữ nhật ký | **120 ngày** |

## 3. Công thức và quy tắc nên thuộc

**Thi đua Chi đoàn:**
> Tổng điểm = **Điểm thi đua trường** (Ban chấp hành ghi nhận, có thể âm/dương)
> **+ Điểm hoạt động bình quân mỗi đoàn viên** (tổng điểm điểm danh trong kỳ ÷ số đoàn viên)

**Các kỳ thi đua:** Tuần · Tháng · Học kỳ · Năm học. Đồng điểm thì **đồng hạng**.

**Huy hiệu (4 loại điều kiện):** số hoạt động tham gia · giờ tình nguyện · tổng điểm · số hoạt động theo một loại. Đạt ngưỡng thì tự trao.

**Khối của Chi đoàn:** Khối = 10 + (năm học hiện tại − năm vào lớp 10). Quá 12 thì ra trường.

## 4. Sơ đồ để vẽ/nhớ

**Luồng điểm danh:**
```
Quản lý mở điểm danh ─▶ hiện QR (đổi 90 giây)
                              │
Đoàn viên quét ─▶ xem hoạt động ─▶ bấm xác nhận
                              │
                    Máy chủ kiểm tra: mã còn hạn? đang mở? đúng Chi đoàn? chưa điểm danh?
                              │ hợp lệ
         ┌────────────────────┴────────────────────┐
   ghi điểm danh   cộng điểm   cộng giờ tình nguyện   xét huy hiệu   gửi thông báo
   (một giao dịch duy nhất: trọn bộ hoặc hủy hết)
```

**Kiến trúc đơn giản:**
```
 Điện thoại / máy tính ──(HTTPS)──▶ Máy chủ (Vercel) ──▶ Sổ cái dữ liệu (PostgreSQL)
        ▲                                    │
        └──── thông báo đẩy ◀────────────────┤
                                             └──▶ Kho ảnh và tệp (Cloudinary)
```

**Vai trò và quyền:**
```
Quản trị hệ thống ─ cấp/thu hồi tài khoản Ban chấp hành, mọi quyền
Ban chấp hành     ─ quản lý toàn trường (đoàn viên, Chi đoàn, hoạt động, thi đua, nội dung)
Bí thư (là đoàn viên + thêm quyền) ─ quản lý Chi đoàn của mình, soạn bài ở dạng nháp
Đoàn viên         ─ xem hồ sơ, đăng ký, điểm danh, xem điểm/thi đua
```

**Vòng đời một khóa (3 năm):**
```
Năm 1: 10A1 ─(01/09)▶ Năm 2: 11A1 ─(01/09)▶ Năm 3: 12A1 ─(01/09)▶ Đã ra trường
 tài khoản, điểm, huy hiệu, lịch sử được GIỮ NGUYÊN        tài khoản khóa, dữ liệu vẫn lưu
```
